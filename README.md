# doyoon study

집중 타이머, 날짜별 학습 계획, 공부 기록을 제공하는 한국어 공부 도구입니다.

## 사용 기능

- 집중 / 짧은 휴식 / 긴 휴식 타이머와 1~600분 시간 설정
- 일시 정지, 재개, 중간 종료 기록, 선택적 종료 알림음
- 날짜별 할 일, 과목, 예상 시간, 중요 표시, 완료 체크, 수정 및 삭제
- 집중 세션 기록, 최근 7일 그래프, 과목별 시간, 연속 공부 일수
- 브라우저 로컬 저장, JSON 백업 및 중복 없는 백업 병합
- 동일 계획의 내용이 다르면 기존 계획 유지 / 백업 파일의 계획으로 변경 선택
- 키보드 조작과 모바일 화면 지원

## 데이터와 타이머

데이터는 현재 사이트의 `localStorage`에 저장됩니다. 계정 로그인이나 기기 간 자동 동기화는 없습니다. 브라우저 데이터를 삭제하기 전에 백업하세요. 타이머는 실제 종료 시각을 기준으로 계산해 새로고침 후에도 복구됩니다. 브라우저가 종료된 동안에는 소리를 재생할 수 없으며, 다시 열면 종료 시간을 확인해 기록합니다. 휴식 및 일시 정지 시간은 집중 기록에서 제외됩니다. 자정을 넘긴 기록은 기기 현지 날짜별로 나눕니다. 학습 계획 완료 여부는 사용자가 직접 체크합니다.

## 구성

별도 설치나 빌드가 없는 HTML, CSS, JavaScript ES modules입니다.

- `index.html`: 화면과 대화상자
- `styles.css`: 반응형 스타일
- `app.js`: 사용자 인터페이스와 저장
- `core.mjs`: 타이머, 기록 집계, 백업 데이터 검증

이 브랜치 `fix/study-desk-20261005`는 공부 사이트 수정본입니다. 최신 `main`은 축구 사이트로 변경되어 별도로 유지됩니다. 이 브랜치를 `main`에 그대로 합치면 사이트 성격이 바뀌므로 배포 대상 확인이 필요합니다. Vercel 프로젝트 `doyoon`의 운영 배포는 GitHub `main` 브랜치에 연결되어 있습니다. Framework Preset은 Other, Root Directory는 저장소 루트입니다.

## 다른 기기로 기록 옮기기

1. 원래 기기에서 진행 중인 공부 시간을 종료해 기록합니다.
2. 데이터 관리 → 계획과 기록 백업하기로 JSON 파일을 저장합니다.
3. 파일을 옮긴 뒤 다른 기기의 데이터 관리에서 불러옵니다.
4. 수정한 계획을 반영하려면 같은 계획 처리 방식을 `백업 파일의 계획으로 변경`으로 선택하고, 변경 개수를 확인합니다.

새 계획과 기록은 추가되며 같은 ID의 기록은 중복되지 않습니다. 불러오기에서 빠진 기존 계획은 삭제하지 않습니다. 실행 중인 타이머와 알림음 설정은 해당 기기에 유지됩니다. 이 기능은 수동 파일 이동이며 자동 동기화가 아닙니다.
