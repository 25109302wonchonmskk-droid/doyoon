# doyoon score

5개 종목의 경기 일정과 결과를 보여주는 한국어 웹사이트입니다.

## 기능

- 축구: 프리미어리그, 라리가, 분데스리가, 세리에 A, 리그 1, 챔피언스리그
- 농구: NBA, WNBA / 야구: KBO 리그, MLB / 미식축구: NFL / 아이스하키: NHL
- 종목 선택 메뉴와 종목별 리그 필터
- 한국 시간(Asia/Seoul) 기준 날짜 선택과 경기 일정/결과
- 월별 달력과 날짜별 경기 보기, 좋아하는 팀의 이달 일정과 경기일 표시
- 여러 팀 즐겨찾기 저장, 선택한 팀의 경기만 날짜별로 필터링
- 30초 자동 갱신, 수동 새로고침, 진행/종료/예정 상태 필터
- 팀 이름 검색, 경기 즐겨찾기, 경기 상세 및 데이터 제공처 원문 연결
- 종목별 쿼터·이닝·피리어드·연장전 상태 및 구간별 득점표
- 오른쪽 리그 순위표: 12개 리그, 컨퍼런스·지구 선택, 시즌·확인 시각 표시
- 순위표 팀 이름 옆에 현재 3연패 이상인 팀의 연패 수 표시
- 모든 팀의 최근 최대 10경기 전적 열: 승·무·패, NHL 연장·슛아웃 패배 별도 표시
- 데스크톱과 모바일 반응형 화면 (좁은 화면에서는 순위표를 경기 목록 아래에 표시)

## 데이터

Vercel Function `/api/scores?date=YYYY-MM-DD&sport=basketball`이 경기 데이터를 가져옵니다. KBO는 네이버 스포츠, 나머지 리그는 ESPN scoreboard의 공개 JSON 응답을 사용합니다. 인증 키는 사용하지 않습니다. `sport`는 `soccer`(기본값), `basketball`, `baseball`, `football`, `hockey`를 지원합니다. 선택적인 `league` 매개변수로 해당 종목의 리그를 지정할 수 있습니다. 잘못된 종목·리그 조합은 400 응답을 반환합니다.

지정일과 전날을 개별 요청하고 경기 시작 시각을 한국 날짜로 변환해 필터링합니다. 성공 응답은 Vercel CDN에서 15초 캐시하고, 화면은 30초마다 조회합니다. 숨겨진 탭의 자동 조회는 중지합니다. 따라서 점수는 순간 전송이 아니며 제공처의 지연과 캐시 주기가 반영됩니다.

시작 전에는 제공처의 0점 초기값을 스코어로 표시하지 않습니다. 연기/취소/중단은 별도 상태입니다. 일부 리그가 실패하면 해당 리그를 명시하고, 전체 연결 실패는 502 오류로 표시합니다. 실패를 경기 없음으로 처리하지 않습니다. 구간별 득점표는 제공처에 해당 기록이 있을 때만 표시합니다.

즐겨찾기는 브라우저 localStorage에 종목과 경기 ID를 함께 저장하며, 기존 축구 즐겨찾기는 자동으로 이전합니다. 종목별 저장 경기와 날짜를 확인할 수 있습니다. 로그인 및 기기 간 동기화는 없습니다.

좋아하는 팀은 경기 즐겨찾기와 별도로 `doyoon-score-favorite-teams`에 종목별 1개씩 저장합니다. 종목·리그를 선택한 뒤 팀을 고르면 월별 달력에 경기 수를 표시하고, 이달 일정에 상대 팀·홈/원정·한국 시간·경기 상태를 보여줍니다. 날짜나 일정 행을 누르면 그날의 경기 목록도 선택한 팀으로 필터링합니다. `전체 팀 보기`로 해당 종목의 팀 선택을 해제할 수 있습니다. 팀 목록은 현재 리그 순위 응답을 공유하며, 일정 범위는 선택한 리그입니다. 같은 축구팀의 다른 대회 일정을 보려면 리그를 바꿔야 합니다.

팀별 월간 일정은 `/api/team-schedule?league=kbo&team=LG&month=2026-10`처럼 요청합니다. 축구는 ESPN 팀 일정의 완료 경기와 예정 경기를 합치고, 미국 리그는 프리시즌·정규시즌·포스트시즌을 구분해 조회합니다. KBO는 네이버의 월간 일정 전체를 `size=500`으로 요청하고 응답의 총 경기 수와 일치하는지 검증합니다. 모든 일정은 한국 날짜로 월을 구분하며 중복 경기, 시간 미정, 취소 경기, 더블헤더를 처리합니다. 아직 발표되지 않은 일정과 연결 실패를 구분하고 일부 단계의 조회 실패는 화면에 표시합니다. 성공한 월간 일정은 5분 캐시하며 자동 갱신이 켜져 있을 때 다시 조회합니다. 선택일의 점수 갱신은 해당 월간 일정에도 반영합니다.

지원 데이터 피드에는 가용성 보장이 없습니다. 데이터 제공 중단이나 형식 변경 시 연결 코드를 수정해야 합니다. K리그, KBL 및 위에 명시되지 않은 대회는 현재 제공 범위에 포함되지 않습니다.

## 구성과 배포

- `index.html`, `styles.css`, `app.js`: 화면과 클라이언트 기능
- `sports.mjs`: 종목과 리그 목록, 한국 날짜, 스코어·진행 상태 정규화, 즐겨찾기 이전
- `kbo.mjs`: 네이버 스포츠 KBO 응답의 한국 시간·팀·상태 정규화
- `api/scores.js`: Vercel Node.js 24 경기 서버 함수
- `standings.mjs`, `api/standings.js`: ESPN·네이버 스포츠의 리그 순위 정규화와 서버 함수
- `standings-ui.mjs`: 순위표, 리그·그룹 선택, 캐시·갱신·요청 경합 처리
- `streaks.mjs`: 제공처 연패 기록 해석과 축구 리그 경기 기록 검증·연패 계산
- `recent-form.mjs`: ESPN 최근 전적·시즌 경기 기록과 KBO 공식 최근 10경기 기록 검증·결합
- `team-schedule.mjs`, `api/team-schedule.js`: 팀별 월간 일정 조회·정규화, 팀·리그·시즌·한국 날짜 검증
- `team-planner.mjs`: 좋아하는 팀 저장, 달력·월간 일정, 요청 경합과 캐시 처리
- `vercel.json`: 경기·순위·팀 일정 함수 최대 30초와 응답 헤더
- `tests/football.test.mjs`: 기존 축구, 날짜 경계, 스코어, 오류 처리 회귀 테스트
- `tests/sports.test.mjs`: 추가 종목의 상태·득점, 종목별 API, 즐겨찾기 테스트
- `tests/kbo.test.mjs`: 한국 시각, 취소·중단, 승패, 즐겨찾기, 소스 실패 처리 테스트
- `tests/team-schedule.test.mjs`, `tests/team-planner.test.mjs`: 월 경계·일정 병합·빈 일정·오류 구분, 팀 저장과 종목·날짜 전환 테스트

빌드 및 외부 npm 의존성이 없는 정적 프론트엔드 + 서버 함수 구성입니다. 기존 Vercel 프로젝트 doyoon의 GitHub main 브랜치에 배포합니다.

KBO는 `/api/scores?sport=baseball&league=kbo&date=YYYY-MM-DD`로 조회합니다. 네이버 스포츠 공개 경기 응답을 사용하며, 예정 경기의 초기 0점과 취소·중단 상태를 구분합니다. 네이버의 시간대 없는 경기 시각은 한국 시간으로 해석합니다. KBO 상세에는 제공되는 총점과 진행 이닝을 표시하며, 이닝별 득점표는 현재 제공하지 않습니다. KBO 경기 ID에 별도 접두사를 붙여 MLB 즐겨찾기와 구분합니다.

순위는 `/api/standings?league=kbo`처럼 리그 ID로 요청합니다. KBO는 네이버 스포츠 팀 기록, 나머지는 ESPN standings를 사용합니다. ESPN에는 `seasontype=2`(축구는 1)를 요청하여 프리시즌·포스트시즌 성적과 정규시즌 성적을 구분합니다. API의 상위 시즌 표기가 다른 경우 실제 순위 테이블의 시즌 연도를 사용합니다. 순위는 경기 날짜와 관계없이 최신 시즌 기준이며 5분 CDN 캐시와 브라우저 갱신을 사용합니다.

MLB·NFL은 지구별, NBA·WNBA·NHL은 컨퍼런스별로 표시합니다. 제공된 순위·시드 순서를 유지하며 MLB·NFL의 지구 내 순위는 해당 지구의 순서로 표시합니다. 개막 전 0경기 팀은 순위를 만들지 않고 `–`로 표시합니다. 순위 연결 실패는 별도 오류를 표시하며 경기 결과 기능과 독립적으로 처리합니다.

연패 배지는 선택한 리그의 현재 시즌 기록에서 3연패 이상인 팀에만 표시합니다. KBO는 네이버의 `continuousGameResult`, 미국 리그는 ESPN의 `streak`를 사용하며 제공처의 무승부·연장패 집계 기준을 따릅니다. 축구는 ESPN의 해당 리그·시즌 팀별 완료 경기 기록을 날짜 역순으로 계산하며, 승리 또는 무승부에서 연패가 끊깁니다. 경기 수와 승무패 합계가 순위표와 일치하는 경우에만 확정합니다. 축구 추가 조회 실패나 기록 불일치가 있으면 해당 배지를 생략하고 확인 불가 안내를 표시하며 순위표는 유지합니다. 연패 기록은 순위표와 함께 5분마다 갱신됩니다.

최근 전적은 현재 순위표의 시즌·리그 범위에서 완료된 최근 최대 10경기입니다. 10경기 미만이면 실제 경기 수를 함께 표시하며, 0경기는 `경기 없음`, 데이터 오류는 `확인 불가`로 구분합니다. ESPN의 Last Ten Games 기록을 우선 사용하고, 시즌 전체가 10경기 이하이면 검증된 시즌 승무패를 사용합니다. 최근 기록이 없으면 해당 팀의 정규시즌 완료 경기 기록을 조회해 날짜 역순으로 10경기를 집계하며, 축구 연패 계산과 같은 응답을 공유합니다. NHL은 일반 패배와 OT패를 중복 집계하지 않습니다.

KBO 최근 전적은 KBO 공식 팀 순위표의 `최근10경기` 열을 읽습니다. 연도·정규시즌 여부·팀 이름을 검증하고, 네이버 순위의 경기 수·승무패와 일치할 때만 결합합니다. 갱신 시점이 다른 기록이나 일부만 제공된 최근 기록으로 빈칸을 추정하지 않습니다. 좁은 화면에서는 순위표 안에서 가로로 스크롤할 수 있습니다. 최근 전적도 순위표와 함께 5분마다 갱신됩니다.

검사: `npm test` 및 `node --check app.js`.
60개 자동 검사를 통과했습니다. 축구 6개 리그에 더해 NBA·WNBA·MLB·NFL·NHL의 실제 ESPN 응답, 한국 날짜로 정규화된 경기 목록과 구간별 득점을 확인했습니다. KBO는 실제 예정·완료·취소 경기와 경기가 없는 날짜를 확인했습니다. 12개 리그의 실제 순위 데이터와 정규시즌 개막 전 NBA 표시를 확인했습니다. 연패 검사에는 3연패 표시 경계, 승리·무승부 이후 해제, 리그·시즌 분리, 중복·누락 경기, 추가 조회 실패와 종목 전환 시 배지 갱신을 포함합니다. 최근 전적은 10경기 제한, 개막 전·10경기 미만·누락 기록 구분, 정규시즌 분리, NHL OT패, KBO 팀·연도·승무패 일치, 연패 조회 공유 및 종목 전환을 검사합니다. 팀 일정은 KST 월 경계, 결과·예정 경기 병합, 미발표 포스트시즌과 오류 구분, KBO 전체 경기 수·더블헤더, 종목별 팀 저장 및 늦게 도착한 이전 요청 무시를 검사했습니다. 축구·KBO·NBA·WNBA·MLB·NFL·NHL의 실제 팀별 월간 일정도 확인했습니다. 제작 환경의 미리보기 도구 제약으로 실제 브라우저 화면 검증은 수행하지 못했습니다.

## 팀 즐겨찾기와 다운로드 HTML

- `한국야구 KBO` 버튼으로 바로 이동합니다. 순위표의 팀 이름 옆 ☆ 또는 경기 상세의 `팀 즐겨찾기`를 누르면 팀을 저장하고 그 팀의 월간 일정을 표시합니다.
- `내 팀 일정`의 저장 팀 버튼으로 종목이 다른 팀도 전환할 수 있습니다. `전체 팀 보기`는 일정 필터만 해제하며 즐겨찾기는 보존합니다. 팀의 ★를 다시 누르면 즐겨찾기에서 삭제합니다.
- `doyoon-score-saved-teams`에는 종목·리그·팀 ID로 여러 즐겨찾기를 저장합니다. 기존 종목별 선택 팀은 최초 실행 시 이전합니다. 선택 팀과 경기 즐겨찾기 기록도 유지합니다. 브라우저별 저장이며 웹 주소와 로컬 파일 간에는 자동 동기화되지 않습니다.
- `node scripts/build-download.mjs`는 CSS와 JavaScript를 포함한 `downloads/index.html`을 만듭니다. 다운로드 파일은 인터넷 연결 시 운영 사이트의 공개 조회 API를 사용합니다. 로컬 파일의 `#/?sport=baseball&league=kbo&date=2026-10-09` 형식도 읽습니다.
- 조회 전용 `/api/*`는 다운로드 HTML의 접속을 위해 CORS를 허용합니다. 쓰기·로그인·개인 데이터 API는 없습니다.

검증(2026-10-09): 자동 검사 62개 통과. 실제 KBO 월간 팀 일정 조회 성공. 브라우저 렌더링 검증은 실행 환경 연결 제약으로 미완료. 운영 반영은 아직 미완료이며 다운로드 HTML은 신규 API와 CORS 설정 배포 후 실시간 조회가 가능합니다.
