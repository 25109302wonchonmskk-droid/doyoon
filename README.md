# doyoon study

집중 타이머, 날짜별 학습 계획, 공부 기록을 제공하는 한국어 공부 도구입니다.

## 사용 기능

- 집중 / 짧은 휴식 / 긴 휴식 타이머와 1~180분 시간 설정
- 일시 정지, 재개, 중간 종료 기록, 선택적 종료 알림음
- 날짜별 할 일, 과목, 예상 시간, 중요 표시, 완료 체크, 수정 및 삭제
- 집중 세션 기록, 최근 7일 그래프, 과목별 시간, 연속 공부 일수
- 브라우저 로컬 저장, JSON 백업 및 중복 없는 백업 병합
- 키보드 조작과 모바일 화면 지원

## 데이터와 타이머

데이터는 현재 사이트의 `localStorage`에 저장됩니다. 계정 로그인이나 기기 간 자동 동기화는 없습니다. 브라우저 데이터를 삭제하기 전에 백업하세요. 타이머는 실제 종료 시각을 기준으로 계산해 새로고침 후에도 복구됩니다. 브라우저가 종료된 동안에는 소리를 재생할 수 없으며, 다시 열면 종료 시간을 확인해 기록합니다. 휴식 및 일시 정지 시간은 집중 기록에서 제외됩니다. 자정을 넘긴 기록은 기기 현지 날짜별로 나눕니다. 학습 계획 완료 여부는 사용자가 직접 체크합니다.

## 구성

별도 설치나 빌드가 없는 HTML, CSS, JavaScript ES modules입니다.

- `index.html`: 화면과 대화상자
- `styles.css`: 반응형 스타일
- `app.js`: 사용자 인터페이스와 저장
- `core.mjs`: 타이머, 기록 집계, 백업 데이터 검증

Vercel 프로젝트 `doyoon`에 GitHub `main` 브랜치를 연결해 배포합니다. Framework Preset은 Other, Root Directory는 저장소 루트입니다.

## 검증

`node --check app.js`, `node --check core.mjs`로 JavaScript 구문을 확인할 수 있습니다. `TZ=Asia/Seoul node --test tests/core.test.mjs`로 타이머의 정지 시간 제외, 재접속 만료, 자정 분할, 백업 데이터 검증 등 8개 검사를 실행합니다. HTML의 요소 ID, 입력 레이블 연결, JavaScript 대상 요소와 정적 자산도 확인했습니다. 제작 환경의 브라우저 미리보기 도구 제약으로 실제 기기 화면 검증은 수행하지 못했습니다.
